## LinkedIn Post

I built 20+ open-source developer tools and created a cyberpunk terminal portfolio to showcase them all.

No React. No frameworks. Just vanilla HTML, CSS, and JavaScript.

Here's the story:

Two years ago, I started building developer tools in my spare time. VS Code extensions, Telegram bots, CLI utilities, mobile apps — I kept shipping and shipping.

But I had a problem: no way to showcase them all in one place.

GitHub profiles are great for repositories. LinkedIn is great for job hunting. But neither of them could capture the essence of what I was building — an ecosystem of interconnected developer tools.

So I did what any self-respecting developer would do: I built my own portfolio from scratch.

The result? dotUniverse — a cyberpunk-themed interactive portfolio with a fully functional terminal emulator and 20+ hidden Easter eggs.

The terminal has 20+ commands, tab completion, command history, and a virtual file system. Type 'help' to see everything.

The Easter eggs are what people remember:
• BSOD: sudo rm -rf / --no-preserve-root
• The Final Boss: nmap 127.0.0.1

Why vanilla JavaScript?
1. Zero dependencies
2. Loads in milliseconds
3. Forces you to learn fundamentals
4. Will work in 10 years without updates
5. Building from scratch is satisfying

Try it yourself:
🔗 Live: kareem2099.github.io/dotuniverse/
⭐ GitHub: github.com/kareem2099/dotuniverse

What do you think? Should I add more Easter eggs?
